# Takekit

AI-first video editing harness — múltiplos projetos de vídeo em paralelo, orquestrados por chat.

## Estrutura inicial

```
takekit/
├── apps/        # Views: compacta e detalhada
├── engine/      # Orquestrador de projetos de vídeo
├── pipeline/    # Etapas headless (FFmpeg, Whisper, Robust Video Matting, etc.)
├── styles/      # Presets de estilo (ex.: 09-jev)
└── README.md
```
