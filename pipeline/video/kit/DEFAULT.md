# Default de edição: movido para o Style Kit

O estilo default agora é o pacote **Talking Head + Motions** (id `talking-head-motions`,
antes chamado de "default 09-jev"), na galeria de estilos do Takekit:

- Briefing (o que está travado + pipeline): [styles/talking-head-motions/prompt.md](../../../styles/talking-head-motions/prompt.md)
- Storyboard, palcos, caption, cuts, SFX, transições e scripts: os demais arquivos do
  [pacote](../../../styles/talking-head-motions/)

Numa thread do Takekit vale o estilo escolhido nela (`styleId`); o harness injeta o `prompt.md`
do pacote no prompt do agente. Spec: [docs/style-kit/SPEC.md](../../../docs/style-kit/SPEC.md).
