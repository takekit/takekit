# Omitted from takekit port

To keep the prototype repo lean, these binary dumps were not copied (or were stripped):

- `filmburns/` large `.mp4`/`.mov` packs (see `filmburns/README.md`)
- `backgrounds/` video loops
- `music/` audio files
- `reels-covers/` image pack
- SFX wavs larger than 5MB
- `projects/*/exports`, raw `.mov`, bake/overlay frame dumps

Point `TAKEKIT_ASSETS` at a folder with the full media (music, filmburns) for a real edit.
